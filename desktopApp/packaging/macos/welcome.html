Install BitChord

BitChord is a desktop client for YouTube Music: search, playlists, lyrics, Automix transitions and offline downloads, in one window.

This installer copies BitChord.app to your Applications folder.

  • Every dependency travels inside the app — no Java, FFmpeg or other runtime to install.
  • Sound Search asks for microphone access the first time you use it.
  • Requires macOS 12 or later.

You can remove BitChord later by dragging it from Applications to the Bin.
